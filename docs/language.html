Language

Scripts are a subset of Python, parsed with ruff_python_parser. There is no import system. Host tools are registered by the runtime.

  • assignment, unpacking, and augmented assignment
  • calls, including keyword arguments on print
  • if / elif / else and conditional expressions
  • for over a list or string
  • lists, dicts, f-strings, comparisons, boolean operators, and arithmetic
  • subscripts and common string, list, and dict methods
  • builtins len, range, sum, min, max, sorted, reversed, enumerate, zip, any, all, and list
  • try / except ToolError and a bare except
  • xs.append(v) and xs.extend(ys) on a plain name, rewritten to xs += [v] and xs += ys (values are immutable, so other receivers such as d["k"].append(v) are an error)

Not supported, each with a one-line error and a fix hint: import, def, class, while, with, lambda, comprehensions, and await.

A bare except catches tool failures and ordinary runtime errors. except ToolError catches only tool failures. Cancellation is not caught.
