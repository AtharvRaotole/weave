CLI

pip install installs the weave command. cargo run -p weave-cli -- is the same four commands for echo and const tools, without Python.

weave check FILE [--tool name=weather,effect=read,arity=1]
weave run FILE [--tool name=weather,effect=read,behavior=echo] [--trace-out trace.json]
weave replay FILE --trace trace.json [--tool ...]
weave trace trace.json

behavior=echo returns the single positional argument. behavior=const returns the result string. Effects are pure, read, reversible, and irreversible.

trace prints one row per recorded call: sequence, line, tool, effect, arguments, result, and error.
