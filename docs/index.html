Weave

A small Python-like language for agent tool calls. Independent pure and read calls run together. Irreversible calls wait until the script is complete.

Install

cargo test --workspace
python3 -m venv .venv
.venv/bin/pip install 'maturin>=1.8,<2'
.venv/bin/maturin develop --release
.venv/bin/weave check examples/hello.weave --tool name=weather,effect=read,arity=1

Weave 1.0 wheels (distribution weave-lang, import weave) are on the GitHub releases page. Read Running Weave in production for guarantees, non-guarantees and the threat model. v0.1.0 is a historic experimental release with known defects. Nothing is published to PyPI; the name weave belongs to another project.

A script

city = "Paris"
temp = weather(city)
print(temp)
import weave

@weave.declare(effect="read", timeout_ms=1000)
def weather(city: str) -> str:
    return f"18C {city}"

def main():
    engine = weave.Engine()
    engine.install([weather])
    print(engine.run(open("script.weave").read()).stdout)

if __name__ == "__main__":
    main()

@engine.declare(...) registers the function immediately. @weave.declare only marks it, and install registers the marked functions later. Mark tools at module scope when they will run in a worker process.
