weave Playground
Docs GitHub

For people building LLM agents

Let your agent write one short script instead of a dozen tool calls

Weave is a small Python-like language for tool calling. The model writes one script, Weave checks it and shows you every write before anything runs, then runs the calls that don't need each other at the same time.

Code and docs on GitHub

This page runs the real Weave runtime in your browser (compiled to WebAssembly) against fake tools with set delays. No model, no network, nothing leaves the page.
