One script instead of many tool turns.

The model writes a small Python-like script. Weave checks every call before anything runs, starts independent reads together, and keeps writes in program order. This page runs the real Weave parser, check and scheduler, compiled to WebAssembly. The tools are mocks with fixed latencies on a virtual clock, so nothing leaves your browser.
